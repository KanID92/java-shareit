Сервис для **шеринга** вещей. 
Дает возможность пользователям рассказывать, какими вещами они готовы поделиться, находить нужную вещь и брать её в аренду на какое-то время.
Сервис позволяет бронировать вещь на определённые даты и закрывать к ней доступ на время бронирования от других желающих. На случай, если нужной вещи в сервисе нет, у пользователей есть возможность оставлять запросы.  По данному запросу можно добавлять новые вещи для шеринга.

Основные сценарии:
- Добавление новой вещи.
- Редактирование вещи.
- Просмотр владельцем списка всех его вещей с указанием названия и описания для каждой из них.
- Поиск вещи потенциальным арендатором.
- Добавление нового запроса на бронирование.
- Подтверждение или отклонение запроса на бронирование.
- Получение данных о конкретном бронировании (включая его статус).
- Получение списка всех бронирований текущего пользователя.
- Получение списка бронирований для всех вещей текущего пользователя.
- Добавление отзывов
- Добавление запроса вещи
- Добавление ответа на запрос
